- **Asset, Credential, Relationship and MemoryCandidate collection reads use the shared scoped-search helper.**
  Each composes its owner-only read scope with the query's own conditions the same way Memory reads do: the scope is the outermost condition, and every caller condition is kept. Credential searches by an agent return rows without `tokenHash`, as by-id reads already do, and a selection of `tokenHash` alone is refused. Anonymous denials, internal reads and by-id reads are unchanged.
