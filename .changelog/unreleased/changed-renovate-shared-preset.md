- Renovate's configuration has been split into a **shared org preset** (`.github/renovate-preset.json`) and a **per-repo overrides file** (`.github/renovate.json`). The preset establishes the common policy: pin version updates, enforce a 7-day bake-time cooldown (matching `check-dep-ages.mjs`), group non-major updates into one PR, pin Docker digests, and group GitHub Actions so sub-actions land together. The per-repo file extends the preset and holds only Flair-specific exceptions (workspace-internal `@tpsdev-ai/*` dep exclusions, keep-current allow-list for Harper, pip manager for `packages/adk-flair`, bun manager for the `bun.lock` lockfile). CLI and bob repos can extend the same preset via `github>tpsdev-ai/flair//.github/renovate-preset`. See the [supply-chain policy](docs/supply-chain-policy.md) for details and the PR body for the full config diff.
