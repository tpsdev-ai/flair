- **A copy of untrusted JSON no longer loses or re-homes an own `__proto__` key where Flair hashes, signs or forwards a record (flair#2235).** Those sites now copy through one `src/lib/proto-safe-record.ts` helper that defines every own key on an `Object.create(null)` record, so the key is data on the copy rather than a prototype; `withoutNullArguments` is the site where an own `__proto__` key was previously re-homed as a prototype. A source lint, not a proof, checks `Object.assign` with literal targets, loop-copy targets initialized with `{}` matched by variable name within a file, and `JSON.parse` spreads in `src/` and `resources/`, with counted allowlist entries. Compatibility: for a record carrying an own `__proto__` key, the source-field envelope hash and the federation signature change at this version; a peer on an older version fails that record's signature check (fail-closed). Records without such a key are byte-identical.
