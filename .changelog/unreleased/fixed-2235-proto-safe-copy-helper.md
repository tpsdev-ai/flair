- **At the sites this change covers, a copy keeps an own `__proto__` key as data (flair#2235).** Those sites now use one `src/lib/proto-safe-record.ts` helper that copies each selected key onto an `Object.create(null)` record with `Object.defineProperty`. A source lint, not a proof, checks `Object.assign` with literal targets, loop-copy targets initialized with `{}` matched by variable name within a file, and `JSON.parse` spreads in `src/` and `resources/`, with counted allowlist entries. Compatibility: the hash changes only when such a key sits inside a selected source-field value; the signature changes, and an older peer refuses the record (fail-closed), only when such a key is retained in the signed federation payload. Ordinary JSON values under unmodified built-ins are byte-identical without such a key.
