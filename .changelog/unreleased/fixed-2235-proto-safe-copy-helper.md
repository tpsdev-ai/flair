- **A copy of untrusted JSON no longer loses or re-homes an own `__proto__` key where Flair compares, hashes or signs a record (flair#2235).** Those sites now copy through one `src/lib/proto-safe-record.ts` helper that defines every own key on an `Object.create(null)` record, so the key is data on the copy rather than a prototype. A source-scan test fails the build on a new plain-object copy via `Object.assign`, an own-key loop into `{}`, or a spread of a `JSON.parse` value.
