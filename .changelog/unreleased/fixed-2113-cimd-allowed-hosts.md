- **`flair mcp enable --cimd-allowed-hosts` now writes the allowed-hosts list into the component `config.yaml`, or refuses.** In 0.57.0 the flag's value only appeared in the command's output, and the served list did not change.

  On a non-Fabric instance the command sets `mcp.clientIdMetadataDocuments.allowedHosts` in the `config.yaml` it edits for `mcp.enabled` (`./config.yaml`, else `~/.flair/config.yaml`), reads the file back before restarting the instance, and prints the list it read. If the write or the read-back fails, the command stops before the restart. It refuses the flag before changing anything for a `*.harperfabric.com` instance, for an entry that is not a lowercase bare hostname (such as a URL, a port, a wildcard or an empty entry), and when that `config.yaml` is missing or has no `@harperfast/oauth` `mcp` block. Without the flag the list is not changed.
