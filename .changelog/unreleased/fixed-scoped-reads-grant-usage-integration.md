- **Integration, MemoryUsage and MemoryGrant reads use the shared read-scope helpers, and the shared scoped search keeps every caller condition.**
  Their collection reads apply the read scope as the outermost condition of the query, as Memory, Message and WorkspaceState already do, and their by-id reads go through the shared by-id gate. The shared scoped search now keeps `conditions` given as a single object and places a lone caller condition directly under the scope, so a caller's conditions only narrow the rows an agent may read and a single-condition query is accepted.
