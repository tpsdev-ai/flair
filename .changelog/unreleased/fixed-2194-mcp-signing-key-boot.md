- The shipped `config.yaml` no longer declares `mcp.signingKeyPem`. Without a pin, minting uses the persisted key or creates one. `flair mcp enable` no longer generates a signing-key file or stages `FLAIR_MCP_SIGNING_KEY_PEM` (nothing read it once the pin left the shipped block). An install that wants a fixed key adds the `signingKeyPem: ${FLAIR_MCP_SIGNING_KEY_PEM}` line and stages the variable.
