- The shipped `config.yaml` no longer declares `mcp.signingKeyPem`: `@harperfast/oauth` 2.8.1 refuses the plugin's load when that whole-token placeholder is unresolved, which degraded every MCP-on boot with no staged key. Without a pin, minting reuses a persisted key or generates and persists one if the key table is empty. An install that wants a fixed key adds the `signingKeyPem: ${FLAIR_MCP_SIGNING_KEY_PEM}` line and stages the variable.
