- **`flair init` retries the using-flair skill write when the instance reports an embedding provider timeout.** After the instance refuses that write with 503 `memory_provider_timeout`, init waits 2 s and runs the seed again if its existing 180 s bound on the write leaves time for the wait. When the write does not finish within that bound, init reports `skill_seed_write_failed` with the attempts and the time spent.
