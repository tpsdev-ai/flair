- **`flair memory add` gives each command its own collision-resistant memory id, and its provider-timeout retries reuse that id.**
  The id was the agent id plus the current millisecond, so two adds by one agent in the same millisecond wrote one memory row: the server's `PUT /Memory/<id>` overwrites an existing row. The id now carries a random UUID suffix, computed once per command, so a retried add still writes a single row. `flair memory write-task-summary` builds its id the same way.
