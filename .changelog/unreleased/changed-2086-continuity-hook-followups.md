- **flair-client adds `loadPrivateKeyBounded` for asynchronous, size-capped key reads, and the continuity record's redaction covers more credential shapes (#2086).** FlairClient uses the bounded variant so a hook binary's process deadline can interrupt the read. Redaction now also covers PGP `PRIVATE KEY BLOCK` blocks and Stripe, Hugging Face, Groq and PyPI key prefixes; a prefix is matched wherever it starts a word, so text that merely looks like a key is redacted too — over-redaction is preferred to leaving a secret in the record. A new integration test reads the SessionStart record through an ephemeral Harper.
