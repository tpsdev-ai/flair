- **flair-client reads the agent's key file asynchronously with a size cap, and the continuity record's redaction covers more credential shapes (#2086).** The key read is bounded (a non-regular file, or one over the cap, is refused before any byte is read), so a hook binary's process deadline can interrupt it. Redaction now also covers PGP `PRIVATE KEY BLOCK` blocks and Stripe, Hugging Face, Groq and PyPI key prefixes; a prefix is matched wherever it starts a word, so text that merely looks like a key is redacted too — over-redaction is preferred to leaving a secret in the record. A new integration test reads the SessionStart record through an ephemeral Harper.
