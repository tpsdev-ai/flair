- **Errors thrown by `callOpsApi` for non-2xx ops API responses carry the HTTP status, operation and a fixed refusal description; Harper's response text is never included.** Unrecognized `callOpsApi` refusals are reported as withheld; requests without a response report an http(s) target's origin (scheme and host, with the port when it is not the scheme's default) (or "the configured ops target" for any other or unparseable URL) and a fixed category: connection refused, timed out or no response.
