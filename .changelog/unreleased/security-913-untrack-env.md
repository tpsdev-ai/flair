- **Untracked `.env` and added `.gitignore` rules for `.env*` to prevent accidental secret commits.** The `.env` file was previously tracked in the repository but is never loaded by the service-manager deployment shapes (launchd/systemd set environment variables directly). While the tracked file only ever contained the non-secret variable `FLAIR_ADMIN_AGENTS`, a tracked `.env` file presents a path-of-least-resistance for future secret leakage — anyone adding a provider key or admin password to `.env` would produce no friction toward a public commit. Added `.gitignore` rules for `.env` and `.env.*` with a `!.env.example` negation, and shipped `.env.example` documenting that env-based config is not read under service managers.
