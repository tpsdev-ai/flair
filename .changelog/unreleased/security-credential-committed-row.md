- **Non-admin owner Credential PUT and PATCH confirm mapping fields in their write transaction.** When the row read for confirmation differs from the row the decision was made on in status, kind, provider, subject or principal, the write returns `stored_row_changed` (409) and the owner's write transaction is aborted, including every element of an array PUT. An administrator change observed by the confirmation is retained on refusal; a change committed after the confirmation read and before the commit is not seen.
