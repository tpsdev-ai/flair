- **On POSIX, agent key provisioning requires a successful directory sync before registration, including when a retry reuses the key.** Before writing a key, provisioning refuses a keys directory that is a symlink, not a directory, or owned by another user. After `flair agent rotate-key` installs a replacement, a failed directory sync warns and leaves the new key in place. Windows skips directory syncing and these directory checks. ([#3167](https://github.com/tpsdev-ai/flair/pull/3167))
