- **A new agent key's directory entry is synced before registration on POSIX, including when a retry reuses it.** A reused key is synced before it is returned, and a keys directory's parent is synced on creation and again when a retry finds the directory in place. A failed sync refuses. A direct `createAgentKeyFile` call leaves the published key in place; `flair mcp grant` removes a key it just published when a later step fails. A keys path that is a symlink, a non-directory or another owner's directory is refused.
