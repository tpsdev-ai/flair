- **`flair init` names the Harper already holding the port when a later call is rejected.** After init skips its own start, an operations-API 401 is that process's admin password, not a bad `--admin-pass`. The message names the pid and data directory when they can be read, and prints `kill` plus `flair stop`. The same naming is used when init refuses up front because the port is already taken and this data directory has no admin user. Init does not stop a process it did not start.
