- **`flair init` stops before authenticating to a different data directory.** When the process already on the HTTP port has another data directory, init names it and exits before any authenticated request. A different directory does not prove the admin passwords differ, and the process on the HTTP port is not assumed to be the one that rejected an operations-port call. A pid is named only when it holds the port that answered; otherwise the listener stays unattributed. `flair stop` is offered only when that data directory still records the process. Init does not stop a process it did not start.
