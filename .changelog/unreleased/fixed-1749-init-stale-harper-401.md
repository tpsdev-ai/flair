- **`flair init` stops before authenticating when it can read a different data directory.** When init can read another data directory from the process on the HTTP port, it names that directory and exits before any authenticated request. An unreadable directory is not treated as a different instance. A different directory does not prove the admin passwords differ, and the process on the HTTP port is not assumed to be the one that rejected an operations-port call. A pid is named only when one stable holder of the port that answered can be tied to the failure; otherwise the listener stays unattributed. `flair stop` is offered once, and only when that command would act on this listener — it has no `--data-dir` and always uses the default data directory. Otherwise the remedy is the process. Init does not stop a process it did not start.
