- **The CLI spawn-budget gate masks JSX text before matching spawn calls and reading deadlines.** In every file kind the gate scans that TypeScript parses JSX in — `.tsx` and `.jsx`, and `.js`, `.mjs` and `.cjs` (parsed as `ScriptKind.JS`) — each JSX text node is replaced from `pos` to `end` with spaces, keeping every line break TypeScript counts (`\n`, `\r`, U+2028 LINE SEPARATOR and U+2029 PARAGRAPH SEPARATOR) and the total length, so an apostrophe, a quote or `//` in that text no longer opens a string or comment in the gate's text-based walks and drops the call or case around it. A JSX attribute's string value is a TypeScript string literal, which the literal masker already handles. The comment masker keeps the same four characters and ends a `//` comment at any of them, and the gate's line-based walks treat all four as line breaks, so a case after a `//` comment ended by `\r`, U+2028 or U+2029 is no longer dropped.
