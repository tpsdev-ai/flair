- **Agent PUT updates an existing agent, keeping its stored `createdAt` and `publicKey`; a PUT to a missing id is refused with 404 `agent_put_requires_existing`.** The replacement is built from a re-read of the row in the PUT's own write transaction: a deletion or a key rotation that commits after the PUT's first read and before that re-read is seen (a deleted agent is refused with the same 404, a rotated key is kept), and one that starts after the re-read is applied after the PUT's write. `POST /AgentSeed` is a creation path, the one the refusal names; `POST /Agent/` also creates a row (administrators only). A key is rotated by `flair agent rotate-key`, an `update` through Harper's operations API.
