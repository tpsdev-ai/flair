- **`flair reembed`'s all-agent run re-embeds every owner's content rows, or only stale ones with `--stale-only`, and exits non-zero when a write or readback failed.**
  The all-agent run sends each two-field re-embed PATCH with the administrator credential it lists rows with, so an owner with no local key is no longer skipped: rows owned by an agent without a key, by the administrator (including the `skill:using-flair` row `flair init` seeds), or by an owner with no Agent row are re-embedded. The final summary is printed for row failures after the listing (an initial ops read failure exits before it), drops the success marker, and reports each distinct row-failure reason once with the number of rows it covers; a readback that fails is reported as a failed read, not as a missing stamp, and a clean run exits 0.
