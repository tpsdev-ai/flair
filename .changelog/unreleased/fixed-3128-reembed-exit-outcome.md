- **`flair reembed` re-embeds every owner's listed rows that have content with the administrator credential, and exits non-zero when a write or its readback failed.**
  The all-agent run sends each two-field re-embed PATCH with the administrator credential it lists rows with, so an owner with no local key is no longer skipped: rows owned by an agent without a key, by the administrator (including the `skill:using-flair` row `flair init` seeds), or by an owner with no Agent row are re-embedded. The final summary drops the success marker on a failed run and reports each distinct row-failure reason once with the number of rows it covers; a clean run exits 0.
