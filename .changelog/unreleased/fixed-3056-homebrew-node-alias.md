- **On Homebrew Node, `flair init` and `flair federation sync enable` record the stable `opt/<formula>/bin/node` alias when it resolves to the same binary.**
  On a Homebrew Node install the launchd plist and the federation sync shim held the realpath `Cellar/<formula>/<version>/bin/node`, which `brew upgrade node` deletes. A plist `flair init` writes and a shim `flair federation sync enable` writes now record the alias instead, and `flair init` makes the same replacement in an existing plist or shim that runs this CLI's install tree (when it accepts the file for re-pointing). The Homebrew alias does not apply to a path outside the Cellar layout. With federation peers configured, `flair doctor` names the node path when the loaded sync job runs the flair-generated shim and the node path on its exec line does not exist, and points at `flair init`.
