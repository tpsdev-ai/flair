- **On Homebrew Node, `flair init` and `flair federation sync enable` record the stable `opt/<formula>/bin/node` alias when it resolves to the same binary.**
  On a Homebrew Node install the launchd plist and the federation sync shim held the realpath `Cellar/<formula>/<version>/bin/node`, which the cleanup step of `brew upgrade node` can remove. A plist `flair init` writes and a shim `flair federation sync enable` writes now record the alias instead, and `flair init` makes the same replacement in an existing plist or shim that runs this CLI's install tree (when it accepts the file for re-pointing). The Homebrew alias does not apply to a path outside the Cellar layout. With federation peers configured and the sync job loaded, `flair doctor` names the node path when the federation-sync unit file names the flair-generated shim as its program and the node path on the shim's exec line does not exist, and points at `flair init`.
