- **`flair principal disable` and `enable` accept `--instance` (or `FLAIR_URL`) for a remote principal (#2114).** They derive the target's operations API as `flair mcp enable` does and require an explicit `--admin-pass`, never the local environment or password file. An explicit instance wins over ambient targets. Redirects and unconfirmed updates refuse; success requires the named row's requested status on read-back. Requests have a timeout and diagnostics redact target URL secrets. With neither `--instance` nor `FLAIR_URL`, the local path uses `127.0.0.1` at `--ops-port`.
