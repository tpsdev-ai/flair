- **Memory gains a validated `hostSource` pointer, server-stamped `receivedAt`, and validation that REJECTS rather than truncates (slice 1 of #1940, PARTIAL).** `Memory.hostSource` is a new nullable JSON attribute (A1) holding a versioned host-object pointer `{ v: 1, host, kind, id, url? }`; existing rows read back `null` and the field sits behind the same clean-upgrade-path idiom as `provenance` (legacy `source` untouched). At `Memory.post()`/`put()` the server validates (A2) against a closed host/kind pair set (`openclaw/run`, `cursor/launch`, `codex/turn`), an id grammar, an https-only url with no userinfo capped at 2048, refuses control characters and bidi overrides, NFC-normalises values, and refuses unknown keys or any `v` other than 1 — rejecting with a named error and storing the canonical fixed-key-order form. The server also stamps `receivedAt` inside `provenance` (A4, server clock, never client-writable; a client-supplied `receivedAt` is ignored), and `hostSource` is never placed inside `provenance` (A5).
