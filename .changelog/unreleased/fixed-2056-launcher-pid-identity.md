- **The launchd launcher and `resolveInstanceServingPid` now identify the process behind `hdb.pid`, not just the pid (flair#2056).**

  A `hdb.pid` is trusted as a live instance only when the process command line is node running harper. A flair#1454 identity sidecar (`flair-daemon.json`) is not required — an instance started by a pre-sidecar flair, or the instance launchd itself starts, serves the data dir without one. A sidecar that names a different pid, or the same pid with a start time outside ±2 s of `ps -o lstart=`, shows the pid was reused and is treated as stale: the launcher execs Harper, whose own `hdb.pid` check still applies, and `resolveInstanceServingPid` falls back to the port listener.
