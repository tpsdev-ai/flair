- **Agent private-key files are owner-only from creation.** `flair agent add`, local and remote `flair init --agent/--agent-id`, `flair principal add`, and `flair import` create a new key at mode `0600` before writing any byte. On POSIX, the keys directory is created or tightened to `0700`, and an existing key wider than owner-only is refused with `chmod 600 <path>` instead of being reused. On Windows owner-only cannot be verified.
