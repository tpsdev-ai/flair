- **On POSIX, agent private-key files are created owner-only.** `flair agent add`, local `flair init --agent/--agent-id`, remote `flair init --target ... --agent-id`, `flair principal add`, and `flair import` create a new key at mode `0600` before writing any byte. The keys directory is created `0700`, and an owned directory with group or world bits is tightened to `0700`. An existing key with group or world bits is refused with `chmod 600 <path>` instead of being reused. On Windows the create path sets the mode and the reuse path neither checks nor sets it.
