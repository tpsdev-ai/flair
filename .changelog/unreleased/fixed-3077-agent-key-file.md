- **On POSIX, agent private-key files are created owner-only.** `flair agent add`, local `flair init --agent/--agent-id`, remote `flair init --target ... --agent-id`, `flair principal add`, and `flair import` create private keys at mode `0600`. Before writing a key, they check the keys directory and remove any group or world access to it, and reuse refuses private keys with group or world permissions. Windows mode bits do not establish owner-only access. ([#3127](https://github.com/tpsdev-ai/flair/pull/3127))
