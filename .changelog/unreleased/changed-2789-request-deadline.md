- **A CLI request that outlives its deadline reports a write's outcome as unknown, never as a failure.** `FLAIR_REQUEST_TIMEOUT_MS` sets the whole-request deadline (the request and the response body read): an integer from 1 to 3600000 ms, default 300000. A GET or HEAD that expires fails; a write that expires raises `ApiRequestOutcomeUnknown` and is not retried. `flair rem restore` records the id as unknown, does not count it restored, and its verification reports whether the id is present and what an id-only check cannot decide.
