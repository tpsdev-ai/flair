- **A write that reaches its whole-request deadline in a `flair rem` command reports an unknown outcome, never a failure.** `FLAIR_REQUEST_TIMEOUT_MS` sets the whole-request deadline (the request and the response body read): an integer from 1 to 3600000 ms, default 300000. A GET or HEAD that expires fails; a write that expires raises `ApiRequestOutcomeUnknown` and is not retried. `flair rem light`, `flair rem rapid`, `flair rem restorative`, `flair rem promote`, `flair rem reject` and `flair rem nightly run-once` print the unknown outcome and exit 3; `flair rem restore` reports `unresolved` and exits 3, and does not write a table and record id again in that run after any unknown write to it. A nightly log append that fails after an unknown write still exits 3 and prints the log failure. Verification reports whether each unknown memory or soul id is present and what an id-only check cannot decide; candidate readback is a follow-up (flair#2789).
