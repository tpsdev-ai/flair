- **A CLI request that outlives its deadline reports a write's outcome as unknown, never as a failure.** `FLAIR_REQUEST_TIMEOUT_MS` sets the whole-request deadline (the request and the response body read): an integer from 1 to 3600000 ms, default 300000. A GET or HEAD that expires fails; a write that expires raises `ApiRequestOutcomeUnknown` and is not retried. `flair rem restore` records the id as unknown, does not count it restored, and skips writing an id whose DELETE outcome is unknown; any unknown outcome makes its result `unresolved` and it exits 3. `flair rem nightly run-once` reports the same `unresolved` status and exit 3 when `POST /MemoryMaintenance` or `POST /ReflectMemories` expires. Verification reports whether the id is present and what an id-only check cannot decide (flair#2789).
