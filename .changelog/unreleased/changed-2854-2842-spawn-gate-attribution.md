- **The CLI spawn-budget gate attributes spawns in JSX attributes and directly assigned, unannotated variable arrows with simple parameters.** A JSX attribute's string value is blanked between its quotes in either quote style before the gate's text-based case and helper walks, so an attribute that ends in a backslash no longer makes the closing quote look escaped and drops the case around the spawn. The body of a directly assigned, unannotated variable arrow with simple parameters is its AST extent, so a spawn on the `=>` line, on the next line, or inside a parenthesized multi-line body belongs to the arrow, and a case calling the arrow without a budget is reported. A case's reported line is the line its `test(`/`it(` starts on. An added `spawn-no-timeout` key is reported as a re-key when it pairs one-to-one with a removed key of identical file, fingerprint, kind and occurrence and the scanned working-tree file is byte-identical to the trusted base blob; the case-level kinds keep strict identity.
