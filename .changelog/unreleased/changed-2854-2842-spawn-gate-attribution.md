- **The CLI spawn-budget gate attributes spawns in JSX-attribute and unannotated variable-arrow code.** A JSX attribute's string value is blanked between its quotes in either quote style before the gate's text-based case and helper walks, so an attribute that ends in a backslash no longer makes the closing quote look escaped and drops the case around the spawn. A directly assigned, unannotated variable arrow's body is the AST extent of that body, so a spawn on the `=>` line, on the next line, or inside a parenthesized multi-line body belongs to the arrow, and a case calling the arrow without a budget is reported. A case's reported line is the line its `test(`/`it(` starts on. A baseline entry whose `spawn-no-timeout` scope moves in a test file that is byte-identical at the trusted base and the PR head — a correct re-attribution — is reported as a re-key, not a new exception; the case-level kinds keep strict identity.
