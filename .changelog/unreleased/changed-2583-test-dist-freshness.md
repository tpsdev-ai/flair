- **The test-harness Harper startup refuses a `dist/` that was not built from the current sources (#2583).** Before loading the component, `startHarper` compares the built `dist/resources` and `dist/cli.js` (which `bun run build` wipes) against their build inputs by mtime; a stale or missing build now fails with a message naming the newer input and the rebuild command, rather than booting the previous build. The check is a no-op for component roots that are not the Flair source tree.
