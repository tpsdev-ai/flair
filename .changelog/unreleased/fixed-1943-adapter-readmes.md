- **Eight README claims in pi-flair, langgraph-flair, flair-mcp, cursor-wake-runner and cursor-flair are corrected to match the actual code.** Auto-capture no longer claims to save all assistant responses or secrets (it skips recognized secret patterns and content under 100 characters, truncating accepted text to 4000 chars). The Flair client URL is configurable and supports admin Basic auth fallback when Ed25519 keys are unavailable. LangGraph's `listNamespaces` no longer presents itself as a public method—it is supported through the `batch()` dispatch. Namespace pre-filtering only applies to non-semantic queries; semantic queries receive no namespace pre-filter from the server, and FlairStore composes rather than inherits FlairClient. The cursor hook-install supports Claude Code and Codex. The MCP server's engines field declares `>=22`, not `>=22.18`. (Refs #1943)
