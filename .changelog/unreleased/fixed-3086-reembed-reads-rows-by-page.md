- **`flair reembed` reads Memory rows page by page on both administrator paths before the first re-embed write.**
  The all-agent read selects by `id` greater than `0` on its first page; the single-agent administrator read filters on `agentId`. Both then page with `id` greater than the last id seen, sorted by `id`, and report how many memories and pages they read. The read stops after 10,000 pages of 1,000 rows and exits non-zero before writing rather than reporting a complete read. The keyless single-agent listing has no paging parameter: when `/SemanticSearch` returns exactly its 10,000-row limit, the command prints a notice naming the count and the `FLAIR_ADMIN_PASS` remedy, then exits 1.
