- **The process liveness probe reports an exited-but-unreaped process (a zombie) as exited.** It decided liveness from signal 0 alone, which a zombie still answers, so `flair doctor`'s stop wait spent its whole deadline on a process that had already exited and then refused to restart. After signal 0 succeeds the probe now reads the process state (`/proc/<pid>/stat` on Linux, `ps -o stat=` on macOS) and treats `Z` as exited; an unreadable state stays alive, so a failed read never reports a live process as exited.
