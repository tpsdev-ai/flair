- **`flair export --include-key` output and keystore seeds are written owner-only over an existing file, and a wider existing passphrase file is refused.** `flair export --include-key` output and keystore seeds replace existing files through a `0600` temp file. A generated passphrase is published at `0600` if its path is absent; when the generated passphrase file is used (`FLAIR_KEY_PASSPHRASE` unset), an existing file with group or world bits is refused unchanged before reading (`chmod 600 <path>`). Unsupported hard links and empty passphrase files are refused. Export reports the mode read after writing on POSIX; on Windows it states that mode bits are not enforced.
