- **`flair restore --replace` refuses before any delete when a skill-assignment Soul row cannot be checked against the server's write rule.**
  In replace mode a `skill-assignment` row whose `metadata.source` is a filesystem path is refused: the server decides that source's durability from its own environment, which the CLI cannot know. For a source that is not a filesystem path the copied rule refuses a non-durable source or a non-boolean `optOut`. Each refusal names the row and the remedy. Archive admission refuses a Soul row without a non-empty `agentId` as `invalid-row` before the preflight runs. A concurrent same-agent write between the preflight and the PUT is not covered.
