- **A re-embed PATCH now writes from the row it re-reads after the vector resolves (#2390).** `Memory.patch()`'s re-embed request (`flair reembed` and direct PATCH requests) computes the vector outside the write, then re-reads the row inside the write's own transaction and builds the record from that row — a field another writer committed before that read is kept. It re-checks the owner against the current owner, and re-embeds when the stored text changed (bounded); exhaustion is `reembed_row_changed`.
