- **Memory updates now keep a record's stored `private` or `shared` visibility unless the write sets a new one**, on PUT, PATCH, the feed write path, the admin reindex path and the federation merge (a legacy stored value that is neither is not carried). A PATCH that sets visibility or durability is checked by the same guards as PUT; a PATCH with a null or undefined visibility is no change. A failed existing-record lookup now fails the write. Ids generated by the feed and by agent seeding include a random UUID. A federation record is applied only when its payload carries its envelope's id.
