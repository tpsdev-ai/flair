- **Remote `flair init` saves Flair's generated administrator password before the cluster change that applies it.** With Fabric provisioning, init writes the password to its owner-only credential file before the first cluster write; a failed save exits non-zero naming the file and the remedy, and leaves the cluster unchanged. If the cluster change fails after the save, the error names the saved file, and a run that had no earlier credential file keeps the saved value for the next run. When a credential file already exists, init replaces it after the cluster change succeeds and leaves it unchanged when the change fails. A failure of the existing-user read refuses with the error and no cluster write.
