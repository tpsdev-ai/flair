- **The CLI spawn-budget gate reads a spawn's deadline only from an options object literal, written inline or as a `const` identifier's initializer.** The argument or initializer, once parentheses and `as`/`satisfies`/`!` are removed, must be the literal itself, with no spread, computed key, method, accessor or `__proto__` key and exactly one `timeout: <value>` property whose value passes the gate's numeric-literal rule. The identifier must be declared once, not exported, and otherwise referenced in the file only as the options argument of a spawn the gate finds inside the declaration's scope, in a file with no `with` statement and no `eval`. Any other options argument, such as `{ env: { timeout: 5000 } }`, `{ timeout: 5000 } && {}`, a literal with a later spread or a `let` identifier, is no deadline.
