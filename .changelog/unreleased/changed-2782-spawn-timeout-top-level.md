- **The CLI spawn-budget gate reads a spawn's deadline only from an options object literal written in the call.** Where the call takes an argv array before its options (`Bun.spawn`, `Bun.spawnSync`, `spawn`, `spawnSync`, `execFile`, `execFileSync`), the options count only after an array literal there, because `Bun.spawn({ cmd }, …)` and `spawnSync(command, options, …)` ignore a later argument. The options argument, once parentheses and `as`/`satisfies`/`!` are removed, must be the literal itself, with no spread, computed key, method, accessor or `__proto__` key and exactly one `timeout: <value>` property whose value passes the gate's numeric-literal rule. An options identifier is no deadline whatever it holds, and so is a literal that breaks these rules, such as `{ env: { timeout: 5000 } }`, or a larger expression such as `{ timeout: 5000 } && {}`.
