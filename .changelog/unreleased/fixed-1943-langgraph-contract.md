- **`FlairStore` implements LangGraph's `BaseStore` interface, and its documentation describes what it does.**
  `FlairStore` adds public `listNamespaces()`, `start()` and `stop()`, so it can be passed wherever LangGraph expects a `BaseStore`, including a compiled graph's `store`. `batch()` publishes LangGraph's precise per-operation result type, `OperationResults<Op>`, instead of the wide `any[]`; the peer types are imported as types only, so the package still loads without the checkpoint package at runtime. A new unit-lane step type-checks the contract test, so a class that stops satisfying `BaseStore` fails the lane instead of passing under Bun's type-stripping. The README, source comments, package description and integrations catalog now describe its identity options, default visibility and federation behaviour, persistence, retrieval and namespace-enumeration limits as the code implements them.
