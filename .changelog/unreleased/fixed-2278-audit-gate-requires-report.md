- **The dependency audit gate checks each audit stage's output, exit status and stderr (flair#2278).** The bun and npm stages now fail on a JSON value that is not an object, on an object whose `error` property is a string or an object, on a recognized failure line in the tool's stderr (bun `error:` or `audit request failed`; npm `npm error` or `npm ERR!`), and on a non-zero exit with a report that lists no advisories. The npm stage also fails when the `vulnerabilities` object is missing, the empty object `{}` included. Zero-advisory output with exit 0 is accepted by the stage parser when it satisfies the shape checks and has no matching stderr failure line; the existing allowlist checks still determine the gate result.
