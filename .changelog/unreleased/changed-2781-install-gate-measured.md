- **The global-install gate measures Flair's installed dependency graph.** `scripts/check-global-install-lockfile.mjs` starts at the installed `@tpsdev-ai/flair` package and resolves each dependency its packages declare the way Node does, counting each resolved package directory once; bundled `node_modules` copies are reached that way and unrelated packages in the prefix are not. The count is compared to the reviewed floor in `.github/install-weight-budget.json`, and a nonzero or missing npm exit status fails before the tree is evaluated. npm's "added N packages" summary is reported for information only, because it omits the copies harper now ships as `bundleDependencies`.
