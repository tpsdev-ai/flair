- **`flair mcp grant` creates its private key owner-only on POSIX and refuses to replace an existing key file.**
  The grant checks both key paths before generating a key: an existing private or public key path is refused with a message naming it, instead of being silently overwritten. Each created key's identity comes from its temp file's descriptor before publication. If the Agent insert or a later step fails, a key file is removed only if, when checked, it still names the file the grant created; a path replaced between that check and the unlink can still be removed, which a POSIX unlink by name cannot prevent. The keys directory is owner-only (0700 on POSIX), so only a process running as the same user can make that swap. Anything left is named in the error with the reason.
