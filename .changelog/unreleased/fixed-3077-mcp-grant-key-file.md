- **`flair mcp grant` creates its private key owner-only on POSIX and refuses to replace an existing key file.**
  The grant checks both key paths before generating a key: an existing private or public key path is refused with a message naming it, instead of being silently overwritten. If the Agent insert or a later step fails, a key file is removed only while its path still names the file the grant created; anything left is named in the error with the reason.
