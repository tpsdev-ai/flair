- **`flair keys prune --apply` archives keys owner-only, and `flair mcp grant` removes a failed grant's keys only on an acknowledged Agent delete.** The archive directory must be a directory the current user owns with no group or other bits (a missing one is created that way, an existing wider one is tightened); a successfully moved private key is left at `0600`, and a key that cannot be made so stops the command with the remedy. A failure after the insert request is sent deletes the Agent and removes the keys only on an acknowledged delete; otherwise the error says the Agent may exist and the keys were kept, or that the Agent was deleted but key cleanup failed.
