- **`flair keys prune --apply` archives keys owner-only, and `flair mcp grant` separates pre-insert from post-insert key cleanup.** Before the insert request is sent, cleanup runs without a server acknowledgement; after it is sent, only an acknowledged Agent delete removes the keys. On POSIX the archive directory must be a directory the current user owns with no group or other bits (a missing one is created that way, an existing wider one is tightened); where `process.getuid` is unavailable the archive move is refused and nothing is moved. A successfully moved private key is left at `0600`, and a key whose `chmod` fails or that is still wider after it stops the command with the `chmod 600` remedy. After the insert request is sent, a failure deletes the Agent and removes the keys only on an acknowledged delete; otherwise the error says the Agent may exist and the keys were kept, or that the Agent was deleted but key cleanup failed.
