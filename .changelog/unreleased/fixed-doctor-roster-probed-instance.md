- **`flair doctor` verifies that the ops endpoint it reads its Agent roster and home checks from is the instance it probed, before either read.** It picks the candidate ops endpoint with the port-pair rule `flair agent stamp-home` uses, then requires the probed HTTP port and that endpoint to report the same instance identity. When it cannot, both checks are reported as a pair-refused check that did not run — with the reason and a remedy — instead of a read from another instance.
