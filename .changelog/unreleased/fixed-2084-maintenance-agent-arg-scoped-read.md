- **Memory maintenance refuses an admin-supplied `agentId` that is not a non-blank string, and a non-dry agent-scoped run reads only that agent's pointer rows.**
  An admin run is fleet-wide only when the request body has no `agentId` field. A supplied value that is not a non-blank string (a present `undefined`, `null`, empty, blank, or non-string) is refused with 400 `agentId must be a non-blank string` before any cleanup runs, so nothing is removed. In a non-dry run, a run scoped to one agent searches `MemoryHostSource` by its indexed `authorId` instead of scanning the table and filtering in process, and a fleet-wide admin run still scans every pointer row; a dry run skips the pointer sweep. For every request still accepted (an absent `agentId`, a non-blank string, or any non-admin request), counts, removals, and the post-commit read are unchanged (#2084).
