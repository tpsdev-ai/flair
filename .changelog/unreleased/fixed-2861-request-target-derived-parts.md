- **A signed request is verified over the request target its route serves, and `/AdminMemoryCandidates/{agentId}` reads the query the raw target carries (#2861).**
  A request target that WHATWG URL parsing would rewrite is answered `400 non_canonical_request_target` before signature verification, and before the candidate listing reads its query. A target the parser derives unchanged, including an encoded `#`, `%2F` and `%5C`, is handled as before.
