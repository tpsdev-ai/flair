- **FLAIR_MCP_OAUTH=on now fails loudly at boot if `@harperfast/oauth` is absent from config.yaml.** Previously the server booted into a silently non-functional state: the operator set the flag, nothing errored, but the authorization server's routes (discovery, authorize, token, JWKS) never mounted. The boot guard names what is set (`FLAIR_MCP_OAUTH`), what is missing (the `@harperfast/oauth` component declaration), and the exact config.yaml entry to add.
