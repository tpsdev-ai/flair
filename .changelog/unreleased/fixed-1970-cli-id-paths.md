- **CLI request paths built from a record id percent-encode the id as one path segment (#1970).** `flair memory`, `relationship`, `soul`, `restore`, `import`, `reembed`, `test`, `migrate-harness-memory`, the `doctor` probes, and the `/Agent/<id>` reads in `agent`, `principal`, `init` and `export` build `/Memory/<id>`, `/Relationship/<id>`, `/Soul/<id>` and `/Agent/<id>` through one helper (`src/lib/record-id-path.ts`), so an id containing `/`, `?`, `#`, `%` or a space addresses exactly that record. The signed `PUT /OrgEvent/<id>` signs the same encoded path it sends. An id that is exactly `.` or `..` is refused before any request, because URL normalization would move the path. `flair export` refuses a failed `/Agent/<id>` read with the failure named, and reserves "not found" for a 404.
