- **CLI record paths encode IDs as one path segment (#1970).** CLI record reads and writes for Memory, Relationship, Soul, Agent, OrgEvent, WorkspaceState, IdpConfig, MemoryCandidate and FederationPeers use `src/lib/record-id-path.ts`, so reserved URL characters in IDs do not change the addressed record. An ID exactly `.` or `..` is refused before a request. Signed CLI requests now build the final URL first, sign its pathname and query (including any base URL path prefix), and fetch that URL. `flair export` checks each record's required fields before writing an output file; only a definite Agent 404 is reported as "not found".
