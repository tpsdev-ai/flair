- **MemoryReindex confirms re-indexed rows with one agent-scoped index scan per agent instead of an index walk per row.**
  After the re-index writes commit, one `agentId` index scan per agent builds the set of listed ids, and each written id is checked against that set. A written id the set does not contain is still reported as `unconfirmed` with the same message and fields; a failed index scan counts every written id of that agent as an error and includes up to five of them as samples. (#2709)
