- **A schema validation failure on the instruction-version record or its event is now a server error.** Their caller-derived fields are coerced to the schema's types where they are assigned, so a failure is a server defect; both rows are validated with their table's own validator before staging, and a failure aborts the write with its existing 5xx response and commits nothing. A Memory successor or close row carries the caller's fields without that coercion and keeps its 400 at commit.
