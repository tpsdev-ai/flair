- **Remote `flair init` chooses `add_user` or `alter_user` from the cluster's user list, and refuses case and whitespace variants of the reserved `flair-agent` name.** Provisioning reuses an existing super_user cluster administrator without changing or verifying an existing credential file, and warns with how to verify it. Provisioning requires an array of objects with non-empty string usernames and boolean `super_user` permissions before credential staging or cluster writes. The `--admin-user` help now describes this reuse.
