- **Remote `flair init` chooses `add_user` or `alter_user` from the cluster's user list, and refuses case and whitespace variants of the reserved `flair-agent` name.** Provisioning reuses an existing super_user cluster administrator without changing or verifying an existing credential file, and warns with how to verify it. A malformed user list refuses before any write. The `--admin-user` help now describes this reuse.
