- **Codex init compares agent and URL in recognized sections and refuses pre-header triple quotes.** The Codex "already wired" check now requires the current flair-mcp pin and both env values to match, as the JSON clients already did, so a second init with a new agent rewires a recognized Codex section when the pin guard permits it; an ahead pin is held. An installer-written SessionStart hook is re-pointed when its embedded `FLAIR_AGENT_ID` differs and the existing id/URL and requested id pass the command builder's safety checks; a safe pre-#1007 bare legacy hook is migrated to the pinned form. Codex init refuses detected foreign Flair definitions and either triple-quote delimiter before the candidate header, and with no section it refuses to append after delimiter text anywhere in the file, all before backup or write. An agent id, URL or client value that cannot be written into the section is refused by name before the file is read. Each config-content refusal names its reason and the config-content conditions a re-run of init needs; a file the scan cannot read, the pin guard and a failed write can still stop wiring. The scan reads a value spread over lines (a multiline array or string) as a value, not as keys.
