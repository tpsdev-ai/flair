- **Codex is rewired when `flair init --agent` changes `FLAIR_AGENT_ID` or `FLAIR_URL`.** The Codex "already wired" check now requires the current flair-mcp pin and both env values to match, as the JSON clients already did, so a second init with a new agent no longer leaves Codex on the first one. An installer-written SessionStart hook is also re-pointed when its embedded `FLAIR_AGENT_ID` differs, so re-running `flair init --agent` no longer leaves it bootstrapping the previous agent; a legacy unpinned Flair hook is migrated to the current pinned form.
