- **Codex is rewired when `flair init --agent` changes `FLAIR_AGENT_ID` or `FLAIR_URL`.** The Codex "already wired" check now requires the current flair-mcp pin and both env values to match, as the JSON clients already did, so a second init with a new agent no longer leaves Codex on the first one. The SessionStart hook is re-pointed to the requested agent the same way, so a re-init no longer leaves it bootstrapping the previous one.
