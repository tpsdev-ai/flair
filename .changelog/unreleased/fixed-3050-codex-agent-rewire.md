- **Codex is rewired when `flair init --agent` changes `FLAIR_AGENT_ID` or `FLAIR_URL`.** The Codex "already wired" check now requires the current flair-mcp pin and both env values to match, as the JSON clients already did, so a second init with a new agent rewires Codex when the pin guard permits it; an ahead pin is held. An installer-written SessionStart hook is also re-pointed when its embedded `FLAIR_AGENT_ID` differs and the requested id can be safely written, so re-running `flair init --agent` no longer leaves it bootstrapping the previous agent; a legacy unpinned Flair hook is migrated to the current pinned form when its id and URL can be safely written, and refused by name otherwise.
