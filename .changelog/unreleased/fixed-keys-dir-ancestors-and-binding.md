- **On POSIX, refuse a keys directory under an ancestor another user can change, and bind the key write to the checked directory.** The refusal names the first failing ancestor with its owner and mode; if the key path's parent changes after the link, the key is removed and the command stops. An operator whose keys directory is refused must move it under an ancestor owned by root or themselves that is not group- or world-writable, or fix that ancestor's mode. ([#3138](https://github.com/tpsdev-ai/flair/issues/3138))
