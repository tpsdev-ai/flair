- **On POSIX, refuse a keys directory with an ancestor another user can change, and bind the key write to the checked directory.** An ancestor inside flair's home (`~/.flair`) that you own and that is group- or world-writable is tightened instead, with one notice naming the directory and its old and new modes; any other failing ancestor is refused by name with its owner and mode. If the key path's parent changes after the link, the key is removed and the command stops. An operator whose keys directory is refused must move it under an ancestor owned by root or themselves that is not group- or world-writable, or fix that ancestor's mode. ([#3138](https://github.com/tpsdev-ai/flair/issues/3138))
