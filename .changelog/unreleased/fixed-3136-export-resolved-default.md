- **`flair export` publishes its default output from a temp file and requires the real-home exports directory.**
  After creating the exports directory, the command compares its real path with `<real home>/.flair/exports` once and refuses when they differ, writing no export file. It writes a complete temp file in that directory at the export's mode and links it to the default name, so an existing path is refused and no partial file is published at the default name. A failed write, fsync or link removes the temp; a temp removal that fails is reported with its path.
