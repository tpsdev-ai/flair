- **`flair export` publishes its default output from a temp file and requires the real-home exports directory.**
  After creating the exports directory, the command compares its real path with `<real home>/.flair/exports` once and refuses when they differ, writing no export file. In a directory whose entries are not changed concurrently by another writer, it writes a complete temp file at the requested mode, subject to the process umask, and links it to the default name, so an existing path is refused and no partial file is published at the default name. A failed write, fsync or link attempts to remove the temp; a failed removal is reported with its path.
