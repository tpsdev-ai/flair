- **`flair agent rotate-key` takes a per-agent lock before reading the current key, so two rotations of one agent cannot interleave.** A second rotation of the same agent retries within a bounded wait, then refuses with a path to the lock file; rotations of different agents use separate locks. The lock is released when the run ends, including a failed update that exits 1, and a leftover lock from a killed run keeps refusing until an operator removes it.
