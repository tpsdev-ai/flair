- **`flair agent rotate-key` takes a per-agent lock before reading the current key, so rotations of one agent that use the same keys directory are serialized.** A second rotation of that agent in that keys directory retries within a bounded wait and refuses if the lock is still held after the retries, naming the lock file; a rotation that uses a different keys directory does not share the lock. The lock is released when the run ends, including a failed update that exits 1, and a leftover lock from a killed run keeps refusing until an operator removes it.
