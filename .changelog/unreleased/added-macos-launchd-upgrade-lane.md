- **A macOS continuous-integration lane now exercises the real launchd upgrade path a production install follows.** It starts the previous published release, adopts the instance under launchd the same way `flair doctor --fix` does, upgrades to the build under test from an unpublished tarball, and fails if the upgraded instance never serves on its port. This closes the gap that let a 0.53.0 → 0.54.1 upgrade pass every check and still break a production host (Refs #1671, #1683).
