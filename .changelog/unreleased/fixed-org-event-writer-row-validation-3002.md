- **The A2A message/send and agent-key-register OrgEvent rows are validated before staging.** Their caller-derived fields are coerced to the schema's types where they are assigned; a failure answers HTTP 500 with JSON-RPC error `-32000` and `data.error: org_event_row_invalid` for A2A, or 503 `registration_unavailable` for key registration and commits nothing. The migration ledger and graph-heal OrgEvent writers validate their rows too. Key registration refuses BigInt agent ids (including JSON integers Harper parses as BigInt) and numbers that are not safe integers with 400 and asks for a string id.
